rules 第 12 条），章节序号随剩下的节顺延。周报只登本期最新进展；长期归档进三张清单

## 更正
<**只在确有需要更正的内容时才写这一节**，没有就整节不出现。只收**对读者的更正**：
推翻/补正前期已发布的陈述、撤回已发布的数字或日期、前期标「待确认」现已核实、
某数字改为不再采用及其理由。每条注明是第几期的哪句话。

每条只写三样：**更正后的事实 + 依据的一手来源 + 哪一期的哪个数字/说法不再采用**（rules 第 26 条）。
**不写**「全文逐字复核」「复核无误」「经三路复核」这类核验过程叙述与自我评价。

**不写**核验候选数、通过/否决计数、哪个角度空窗、厂商口径占比这类**我们自己的方法说明**——
那些进 PR 正文，不进刊物。也**不写** agent 运行问题（见 rules.md 第 24 条）。>

## 常见反模式（写完自检）

- [ ] 有没有把分析师预测写进前四节？
- [ ] 有没有哪个数字找不到 URL？
- [ ] 有没有猜作者单位？
- [ ] 有没有为了凑篇幅收旧文 / 营销稿 / 专利？
- [ ] 有没有把「开放问题 / 下期」写进刊物（不该有）？挂账与逐条回应是不是都在 `drafts/open-items.md`？
- [ ] 有没有写「连续第 N 期仍缺」这类缺口计数（不该有）？空的角度是不是整节没出现？
- [ ] 抬头是不是只有「主题」「时间窗」两行（没有把「方法」「说明」行写回来）？
- [ ] 有没有写「方法与局限」这类方法说明节（不该有）？「更正」节是不是只收对读者的更正、只写更正后的结论（没有「逐字复核」这类过程叙述）？
- [ ] 有没有收中文文献（不在覆盖面内）？
